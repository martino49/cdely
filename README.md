# Glovo-Jumia Clone

A multi-vendor e-commerce and delivery platform.

## Features
- Customer, Seller, Rider, and Admin roles
- Real-time tracking
- Payment integration
- Order management

## Setup
1. `npm install`
2. Create `.env` based on `.env.example`
3. Import `database/schema.sql` into your MySQL server.
4. `npm run dev`
